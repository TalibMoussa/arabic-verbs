# مشجرة تصنيف الأفعال

مشروع تفاعلي يهدف إلى تمثيل تصنيفات الأفعال في علم الصرف من خلال بنية شجرية متدرجة.

تجمع المشجرة وجوه تصنيف الأفعال، وتعرض أقسامها وفروعها بطريقة بصرية تساعد على إدراك العلاقات بينها واستيعاب صورتها الكلية.

### المميزات
- عرض التصنيفات الصرفية في بنية شجرية تفاعلية.
- إمكانية فتح الفروع وطيّها.
- البحث عن المصطلحات والصيغ الصرفية.
- إبراز المسار التصنيفي عند اختيار أي فرع أو صيغة.

### المساهمة في إعداد المشروع
أُعدّ هذا المشروع بالاستعانة بأدوات الذكاء الاصطناعي، وهو عمل قابل للمراجعة والتطوير.
